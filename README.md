# Terekty Resort

Первая версия промо-сайта круглогодичной зоны отдыха в Койлыке (Антоновке).

## Локальный запуск
Откройте `index.html` в браузере или выполните `python -m http.server 8000`.

## Публикация в Vercel
1. Загрузите все файлы в корень GitHub-репозитория.
2. В Vercel выберите Add New -> Project.
3. Импортируйте репозиторий `terekty-resort`.
4. Framework Preset: Other.
5. Build Command и Output Directory оставьте пустыми.
6. Нажмите Deploy.

## Важно
Форма пока отправляет заявку в WhatsApp. Реальная оплата не подключена. Проектные изображения нужно заменить или дополнить фотографиями после завершения строительства.
